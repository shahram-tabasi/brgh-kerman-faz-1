# پلتفرم یکپارچه اطلاعات مدیریتی و عملیاتی — شرکت توزیع نیروی برق جنوب کرمان

نمونه اجرایی (Demo) پلتفرم **یکپارچه‌سازی و تجمیع اطلاعات سامانه‌ها** بر اساس شرح خدمات
«طراحی و پیاده‌سازی پلتفرم یکپارچه‌سازی، تجمیع و هوشمندسازی اطلاعات سامانه‌های شرکت توزیع نیروی برق جنوب کرمان».

- گرافیک، لوگوها و قالب بصری از پروژه قبلی *SMART-GRID-COMMAND-CENTER* گرفته شده است.
- **بدون هوش مصنوعی:** همه شاخص‌ها، رنگ‌ها و هشدارها از قواعد صریح و حدود «شناسنامه شاخص» (مطلوب / هشدار / بحرانی) محاسبه می‌شوند و قابل ممیزی‌اند.
- اعداد کلان بر اساس آمار منتشرشده شرکت تنظیم شده و اعداد جزئی **برآوردی / نمایشی** هستند (بخش «منابع داده‌های واقعی»).
- دوزبانه (فارسی راست‌به‌چپ / English) با تقویم شمسی و ارقام فارسی.

## منابع داده‌های واقعی

| مورد | مقدار | مبنا |
|---|---|---|
| حوزه عملیات | ۱۶ مدیریت برق شهرستان | فهرست منتشرشده شرکت (گزارش جدیدتر: ۱۸ شهرستان) |
| مشترکین | ≈ ۷۲۵ هزار | اعلام مدیرعامل: بیش از ۷۲۰ هزار؛ تقسیم بر اساس جمعیت (برآورد) |
| پیک بار | ۱۸۰۰ مگاوات | اعلام مدیرعامل: پیک تابستان گذشته حدود ۱۸۰۰ مگاوات |
| ترکیب مصرف | خانگی + کشاورزی ≈ ۸۰٪ | اخبار جنوب کرمان |
| کنتور هوشمند | > ۱۱ هزار چاه کشاورزی | اعلام شرکت |
| پروژه‌ها | ۳۹۰ پروژه / ۸۲۱ میلیارد تومان؛ ۴۲۵ میلیارد تومان برای پیک ۱۴۰۵؛ پست میانچیل جیرفت | اخبار شرکت |
| تلفات | ≈ ۱۳٪ (هدف ۱۱٪) | میانگین کشور ≈ ۱۰٫۶٪ (برآورد برای مناطق گرمسیر) |

سایر مقادیر (SAIDI هر شهرستان، رضایت، بودجه و …) برآوردی و نمایشی‌اند و در Pilot با داده واقعی جایگزین می‌شوند.

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # بیلد تولید (tsc + vite)
```

## ساختار

```
src/
  data/        داده‌های نمایشی: مناطق، شاخص‌ها، منابع، کیفیت، پروژه‌ها، مالی، مشترکین، سلسله‌مراتب، هشدارها
  pages/       صفحات بالا
  components/  اجزای مشترک (پنل، کاشی شاخص، جدول، نمودار، منشأ داده)
public/brand/  لوگوی شرکت و نشان «بابا برقی»
```
