# پلتفرم یکپارچه اطلاعات مدیریتی و عملیاتی — شرکت توزیع نیروی برق جنوب کرمان

نمونه اجرایی (Demo) پلتفرم **یکپارچه‌سازی و تجمیع اطلاعات سامانه‌ها** بر اساس شرح خدمات
«طراحی و پیاده‌سازی پلتفرم یکپارچه‌سازی، تجمیع و هوشمندسازی اطلاعات سامانه‌های شرکت توزیع نیروی برق جنوب کرمان».

- گرافیک، لوگوها و قالب بصری از پروژه قبلی *SMART-GRID-COMMAND-CENTER* گرفته شده است.
- **بدون هوش مصنوعی:** همه شاخص‌ها، رنگ‌ها و هشدارها از قواعد صریح و حدود «شناسنامه شاخص» (مطلوب / هشدار / بحرانی) محاسبه می‌شوند و قابل ممیزی‌اند.
- همه اعداد **نمایشی / مصنوعی** هستند؛ ساختار داده‌ها مطابق شرح خدمات است.
- دوزبانه (فارسی راست‌به‌چپ / English) با تقویم شمسی و ارقام فارسی.

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # بیلد تولید (tsc + vite)
```

## ساختار

```
src/
  data/        داده‌های نمایشی: مناطق، شاخص‌ها، منابع، کیفیت، پروژه‌ها، مالی، مشترکین، سلسله‌مراتب، هشدارها
  pages/       صفحات بالا
  components/  اجزای مشترک (پنل، کاشی شاخص، جدول، نمودار، منشأ داده)
public/brand/  لوگوی شرکت و نشان «بابا برقی»
```
